# Codomax-Internship-Module-5
This repository contains my mini project - a simple AI-powered application.
## 📚 AI Study Assistant
AI Study Assistant is a simple AI-powered educational application built using Python, Streamlit, and Google Gemini API.

The application helps students learn different topics by generating explanations, study notes, practice questions, and key points.

## 🚀 Features

- 📖 Topic Explanation
- 📝 Study Notes
- ❓ Practice Questions
- 💡 Key Points
- 🤖 AI-generated responses
- 🖥️ Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Google GenAI SDK
